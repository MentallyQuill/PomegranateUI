# PomegranateUI Svelte recipes

These Svelte 5 files are editable source recipes, not runtime package internals. Copy them into an adopter repository with `node scripts/verify-recipes.mjs --copy <recipe-id> --to <directory>`, then own and change the copies there.

Run `npm.cmd run check:recipes` to verify the committed recipe bytes and manifest. The copier records installed hashes and refuses to overwrite adopter-modified destinations. Styling, composition, branding, product information architecture, domain data, and backend integration remain adopter-owned.
