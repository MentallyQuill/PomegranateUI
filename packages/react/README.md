# @pomegranate-ui/react

React bindings and source-ownable structural components over the framework-neutral PomegranateUI core. React remains a peer dependency.

The provider uses the core store as its only UI-state authority. Structural components expose roles, labels, data attributes, class hooks, command controls, unresolved-renderer fallbacks, and per-Widget error containment without shipping a visual theme or Sonder-specific markup.
